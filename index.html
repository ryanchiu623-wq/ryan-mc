連不上？

Java 版顯示 Outdated client 或 Outdated server

版本不對。伺服器跑的是 26.3，客戶端也必須是 26.3。在啟動器裡新增一個 26.3 的安裝設定再進來。

Java 版顯示 Connection timed out

先確認上面的狀態燈是綠的。如果伺服器有開還是逾時，可能是你的網路走 IPv6，換個網路（例如手機熱點）再試一次。

基岩版一直連不上

新增伺服器的畫面有兩個欄位：位址填 bedrock.ryanchiu623.dpdns.org，連接埠填 443，不能留空。遊戲要更新到 26.40 以上；如果剛出新版本連不上，等伺服器跟上更新再試。

出生點附近放不了方塊

出生點周圍 20 格是保護區，只有管理員動得了。往外走一段距離就正常了，或是跟 Ryan 說一聲。

本來好好的，突然全部連不上

伺服器跑在家用電腦上，沒有 24 小時開機。上面的狀態燈是紅的就代表主機關了或重開中，等一下再試，或直接問 Ryan。
